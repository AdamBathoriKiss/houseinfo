# House-Info

## 🇭🇺 Magyar

### Leírás
A **House-Info** rendszer célja, hogy megkönnyítse a közösképviselők adminisztratív feladatait, valamint stabilizálja a nyomonkövethetőséget. A beérkező bejelentéseket kezeli és feldolgozza, továbbá az alkalmazáson keresztül értesíti a lakókat az aktuális eseményekről és információkról.

### Fő funkciók
- Bejelentések fogadása és feldolgozása
- Lakók értesítése applikáción keresztül
- Feladatok nyomon követése

### Telepítés
1. Klónozd a repót:

git clone https://github.com/neved/house-info.git

2. Telepítsd a szükséges függőségeket az alkalmazás dokumentációja szerint.
3. Indítsd el a backend-et és frontend-et (például: `npm install`, `ng serve`, `dotnet build`).

### Használat
- Az alkalmazást helyileg indíthatod el a szerveren.
- Bejelentkezési információkat és tesztfelhasználókat a dokumentációban találsz.

## 🇬🇧 English

### Description
The **House-Info** system aims to facilitate administrative Maintences for property managers and stabilize tracking of issues. Incoming reports are efficiently managed and processed, while residents receive timely updates and information through the app.

### Main Features
- Receive and process reports
- Notify residents via the app
- Track Maintences and workflows

### Installation
1. Clone the repository:

git clone https://github.com/yourname/house-info.git

2. Install the required dependencies as described in the app documentation.
3. Start backend and frontend (e.g. `npm install`, `ng serve`, `dotnet build`).

### Usage
- Run the application locally on your server.
- Login credentials and demo users are listed in the documentation.
